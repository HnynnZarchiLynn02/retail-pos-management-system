
# Retail POS Management System

A full-stack Point of Sale and Inventory Management System.

## Technologies

- Next.js
- React
- TypeScript
- Node.js
- Express.js
- Prisma ORM
- PostgreSQL
- Docker
- Git and GitHub

## Features

- User authentication
- Role-based access control
- Product management
- Category management
- Inventory management
- POS checkout
- Payment management
- Sales history
- Sales reports
